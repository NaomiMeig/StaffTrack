
# StaffTrack

Application desktop de gestion du personnel et de suivi des présences.

## Technologies

- Frontend : React et Vite
- Application desktop : Electron
- Backend : Python et FastAPI
- Base de données : SQLite
- ORM : SQLAlchemy
- Migrations : Alembic
- Tests : Pytest

## Environnement

Application Windows fonctionnant localement, sans dépendance à Internet pour son utilisation quotidienne.

## Statut

Projet en cours de développement.
